# America Real Estate

Plataforma web para análise fundamentalista de **REITs (Real Estate Investment Trusts) americanos**.

O projeto foi desenvolvido para reunir informações financeiras e operacionais de REITs em uma interface simples, moderna e objetiva, permitindo analisar um REIT por vez.

## Funcionalidades

- Pesquisa de REITs por ticker ou nome;
- Página individual para cada REIT;
- Cotação;
- Market Cap;
- Dividend Yield;
- P/FFO;
- P/AFFO;
- FFO por ação;
- AFFO por ação;
- Dívida / Ativos;
- Dívida / EBITDA;
- Taxa de ocupação;
- Histórico de preços;
- Histórico de FFO;
- Histórico de dividendos;
- Gráficos financeiros e operacionais.

## REITs

O sistema é voltado exclusivamente para **REITs dos Estados Unidos**.

Exemplos utilizados no desenvolvimento:

- Realty Income (O)
- Prologis (PLD)
- American Tower (AMT)
- Digital Realty (DLR)
- Simon Property Group (SPG)
- Public Storage (PSA)
- Welltower (WELL)
- VICI Properties (VICI)
- AvalonBay Communities (AVB)
- Extra Space Storage (EXR)

Não fazem parte do escopo ações comuns, ETFs, criptomoedas ou outros ativos.
